# LockIn · พอดี

แอป Android ภาษาไทยสำหรับวางแผนงาน จับเวลาโฟกัส และคั่นก่อนเข้าแอปที่มักไถนาน ข้อมูลกิจวัตรและประวัติเก็บอยู่ในเครื่อง

## ติดตั้ง

[ดาวน์โหลด Pordee.apk รุ่น 1.0](https://github.com/susan2548/LockIn/raw/refs/heads/main/outputs/Pordee.apk) สำหรับ Android 8.0 ขึ้นไป

เมื่อติดตั้งแล้ว เปิด **กฎแอป** เลือกแอปที่ต้องการ และเปิดตัวช่วยกันไถในเมนูการช่วยเหลือพิเศษของ Android จากนั้นตั้งเวลาแจ้งเตือนงานและกิจวัตรได้ในแอป

## ฟังก์ชัน

- จัดการงาน กิจวัตร และการแจ้งเตือน
- เริ่มรอบโฟกัสและตั้งเวลาพักร่วมกันระหว่างแอปที่เลือก
- ดูบันทึกรายวันและภาพรวมรายเดือน พร้อมส่งออกเป็น PNG

## สร้าง APK จากซอร์ส

ใช้ Python 3.8 ขึ้นไป, JDK 17, Android SDK Platform 35 และ Build Tools 35.0.0 กำหนด `ANDROID_HOME` ให้ชี้ไปยัง Android SDK แล้วรัน

```sh
python build_apk.py
```

ไฟล์ที่สร้างจะอยู่ที่ `outputs/Pordee.apk` หากต้องการออกอัปเดตให้เครื่องที่ติดตั้งรุ่นเดิม ให้เซ็นด้วยคีย์เดิมผ่าน `STUDYPACE_KEYSTORE`, `STUDYPACE_STORE_PASS` และ `STUDYPACE_KEY_ALIAS`

SHA-256 ของ APK รุ่นนี้

```text

```
