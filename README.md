# Lock In

แอป Android ภาษาไทยสำหรับวางแผนงาน จับเวลาโฟกัส และคั่นก่อนเข้าแอปที่มักไถนาน ข้อมูลกิจวัตรและประวัติเก็บอยู่ในเครื่อง

## ติดตั้ง

[ดาวน์โหลด LockIn.apk รุ่น 1.2](https://github.com/susan2548/LockIn/raw/refs/heads/main/outputs/LockIn.apk) สำหรับ Android 8.0 ขึ้นไป ติดตั้งทับ Lock In 1.1 หรือพอดี 1.0 ได้โดยเก็บงาน กฎ และบันทึกเดิมไว้

เมื่อติดตั้งแล้ว เปิด **กฎแอป** เลือกแอปที่ต้องการ และเปิดตัวช่วยกันไถในเมนูการช่วยเหลือพิเศษของ Android จากนั้นตั้งเวลาแจ้งเตือนงานและกิจวัตรได้ในแอป

## ฟังก์ชัน

- จัดการงาน กิจวัตร และการแจ้งเตือน
- เลือกเวลาเตือนจากปุ่มเวลาที่ใช้บ่อย หรือพิมพ์ชั่วโมงและนาทีในรูปแบบ 24 ชั่วโมง
- กิจวัตรรายวันเริ่มนับใหม่ตอนเที่ยงคืน ส่วนรายสัปดาห์สะสมตั้งแต่จันทร์ถึงอาทิตย์และเริ่มนับใหม่วันจันทร์
- เลือกเวลาจากหน้าคั่นได้ทุกรอบ โฟกัสได้ 1–240 นาที หรือพักดูได้ 1–120 นาที ระหว่างโฟกัส เวลาพักของแอปจะสิ้นสุดอย่างช้าที่สุดเมื่อรอบโฟกัสจบ
- เริ่มรอบโฟกัสและตั้งเวลาพักร่วมกันระหว่างแอปที่เลือก
- เลือก TikTok, Facebook, Instagram, X หรือแอปอื่นจากชื่อและไอคอนบนเครื่อง ตั้งกฎแยกแต่ละแอปได้
- หน้าคั่นเปิดเป็นหน้าจอ Android แยก ขอสิทธิ์ควบคุมการเล่นเสียงชั่วคราวผ่านระบบ และตรวจแอปที่กลับมาจากรายการล่าสุด ปุ่มกลับหน้าหลักออกจากแอปโดยไม่ให้เวลาพัก
- ดูจำนวนวันที่โฟกัสต่อเนื่องและปฏิทินสัปดาห์ โฟกัสสะสมจากรอบที่จบแล้วครบ 5 นาทีในวันเดียวกันนับเป็นหนึ่งวัน
- ดูบันทึกรายวันและภาพรวมรายเดือน พร้อมส่งออกเป็น PNG

## สร้าง APK จากซอร์ส

ใช้ Python 3.8 ขึ้นไป, JDK 17, Android SDK Platform 35 และ Build Tools 35.0.0 กำหนด `ANDROID_HOME` ให้ชี้ไปยัง Android SDK แล้วรัน

```sh
python build_apk.py
```

ไฟล์ที่สร้างจะอยู่ที่ `outputs/LockIn.apk` หากต้องการออกอัปเดตให้เครื่องที่ติดตั้งรุ่นเดิม ให้เซ็นด้วยคีย์เดิมผ่าน `STUDYPACE_KEYSTORE`, `STUDYPACE_STORE_PASS` และ `STUDYPACE_KEY_ALIAS`

```text

```
